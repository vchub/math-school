# Тема: Вынесение общего множителя за скобки

## 1. Описание темы

Вынесение общего множителя за скобки — это важный алгебраический приём, обратный раскрытию скобок. Он позволяет представить сумму (или разность) в виде произведения, что критически важно для упрощения выражений, решения уравнений и работы с многочленами.

> **Рекомендуемый видеоурок:** [Посмотреть на YouTube](https://youtu.be/ADJEdClfdes?si=Ho1AMRdMrKxFzwWE)

---

## 2. Основная идея и алгоритм

**Основная идея:** Из каждого слагаемого «вытаскиваем» одинаковый множитель и записываем выражение как произведение этого множителя на скобку.

### Алгоритм действий

1.  **Найдите общий множитель:**
    *   Для чисел: найдите НОД (наибольший общий делитель).
    *   Для переменных: выберите переменную, входящую во все слагаемые в *наименьшей* степени.
2.  **Вынесите этот множитель** за скобку.
3.  **Заполните скобку:** разделите каждое исходное слагаемое на вынесенный множитель и запишите результаты в скобках.
4.  **Проверьте знаки:** если выносите *отрицательный* множитель, знаки внутри скобок меняются на противоположные.

> **Важно:**
> *   Если слагаемое полностью совпадает с выносимым множителем (например, $9 : 9$), в скобках остается **1**.
> *   Общим множителем может быть не только одночлен, но и целая скобка (например, $(x+2)$).

---

## 3. Разбор примеров

### Пример 1: Числовой множитель
$$12x - 18y$$
*   НОД чисел 12 и 18 равен 6.
*   Делим: $12x : 6 = 2x$, $-18y : 6 = -3y$.
*   **Ответ:** $6(2x - 3y)$

### Пример 2: "Скрытая" единица
$$9a + 9$$
*   Общий множитель — 9.
*   Делим: $9a : 9 = a$, $9 : 9 = 1$.
*   **Ответ:** $9(a + 1)$

### Пример 3: Переменная
$$a^3 - 5a^2$$
*   Наименьшая степень переменной $a$ — это $a^2$.
*   Делим: $a^3 : a^2 = a$, $-5a^2 : a^2 = -5$.
*   **Ответ:** $a^2(a - 5)$

### Пример 4: Отрицательный множитель
$$-7x - 14y$$
*   Выносим -7.
*   Знаки меняются: $-7x : (-7) = x$, $-14y : (-7) = 2y$.
*   **Ответ:** $-7(x + 2y)$

### Пример 5: Общая скобка
$$a(b+1) - 2(b+1)$$
*   Общий множитель — целое выражение $(b+1)$.
*   **Ответ:** $(b+1)(a - 2)$

## 4. Задания для самостоятельного решения

### Базовый уровень

1.  Вынесите общий множитель: $5a + 10b$
2.  Разложите на множители: $12y - 12$
3.  Вынесите общий множитель: $7x - 21$
4.  Представьте в виде произведения: $15 + 5k$
5.  Вынесите общий множитель: $-4m - 16n$
6.  Разложите на множители: $8c + c$
7.  Вынесите общий множитель: $18 - 27p$
8.  Представьте в виде произведения: $33a - 11b$
9.  Разложите на множители: $-9x + 27$
10. Вынесите общий множитель: $a - 5a$

### Продвинутый уровень

11. Вынесите общий множитель: $a^2 - 6a$
12. Разложите на множители: $8xy + 12y$
13. Вынесите общий множитель: $c^3 + c^5$
14. Упростите выражение вынесением общего множителя: $x(y-z) + 5(y-z)$
15. Разложите на множители: $6a^3 - 3a^2 + 12a$
16. Представьте в виде произведения: $-x^4 - 2x^3 - 3x^2$
17. Вынесите общий множитель: $5(a+b) - c(a+b)$
18. Разложите на множители: $m^2n - mn^2$
19. Упростите выражение: $3x(x-2) - 5(2-x)$ *(Подсказка: $2-x = -(x-2)$)*
20. Найдите наибольший общий множитель для: $16z^2w - 24zw^2$
